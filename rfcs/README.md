# Requests for Comments

RFCs hold open proposals for major conceptual, methodological, compatibility,
or repository-process changes. An RFC makes a question reviewable; it does not
make its proposal an accepted position or validated finding.

## Workflow

1. Copy `0000-template.md` without changing the template.
2. Reserve the next four-digit number.
3. Begin at `draft`; use `open` only when an explicit decision review begins.
4. State scope, claim kinds, evidence, alternatives, dissent, compatibility,
   migration, and validation.
5. Resolve as `accepted`, `rejected`, `withdrawn`, or `superseded`.
6. Add an ADR when an accepted RFC creates a durable decision.
