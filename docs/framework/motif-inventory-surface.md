# The motif inventory as evidence surface

## Exact proposition

The corpus adopts the folkloristic motif inventory — Thompson's
Motif-Index as principal instrument — as the neutral surface on which
its convergence claims must eventually be tested: the systematic
arbitrary-particulars and contact-free-tradition tests that the memory
claims' triggers (0004, 0008) demand have their infrastructure here.
Reading the instrument itself is the speculative step beyond the
cataloguer's principled silence.

An `interpretation`, `contextual`, `speculative` — pre-grounding the
Filing Cabinet Explainer (binds on publication).

## Why neutrality is the value

Thompson built the index refusing interpretation — which is exactly why
results run on it can bind both ways. The record's discipline follows:
the inventory's existence and structure are never themselves evidence;
motif-counting is bound by the independence-of-evidence principle; test
results flow to the claims they test, and the second revision trigger
says so — the first systematic test actually run moves the tested claim
and this record's infrastructure status together. The index-artifacts
objection (collection bias inherited by any test) is carried in full.
