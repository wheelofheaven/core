# The Tradition as preserved knowledge chain

## Exact proposition

The Tradition is the corpus's name for the cross-cultural body of
preserved knowledge handed down within esoteric lineages — the
*shalshelet ha-Kabbalah* above all — traced, on the framework's reading,
to instruction originating with the creators. It connects the canon's
closest-to-truth ranking (`woh-claim-0021`) with the encoding cluster
(0014/0044).

An `interpretation`, `derived`, `speculative`.

## The perennialism firewall

The construct is not perennialism, and the record works to keep it from
becoming it: the chain has a specific proposed origin rather than
timeless universal wisdom; each lineage's self-understanding is
preserved; no esoteric metaphysics is validated; no secret-history
causation is asserted. The unfalsifiability objection — degradation
absorbing any counter-evidence — is carried as the sharpest critique,
and lineage-level historical failure of a claimed link is a named
trigger.
