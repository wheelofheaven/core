# Research agenda

## Priority 1 — Validate the research representation

- Review whether the five framework relations cover real Wheel work without
  forcing unlike claims together.
- Test whether compound claims need decomposition rules.
- Determine how public badges should project from core fields without claiming
  false precision.
- Test source-ID validation against the changing aggregated registry.

## Priority 2 — Elohim-civilization claim map

- Separate canonical source reports from biblical identification,
  civilizational attributes, biological-creation claims, and present-status
  claims.
- Map the exact source passages for each subclaim.
- Identify critical source-study, historical, sociological, and scientific
  alternatives rather than treating all objections as one category.
- Define which parts are in principle empirically discriminable.

## Priority 3 — Anunnaki–Elohim comparative review

- Build a passage-level comparison matrix for the relevant Mesopotamian and
  biblical corpora.
- Review `Anunnaki`, `Anuna/Anunna`, `Igigi`, and `Elohim` across periods rather
  than as fixed rosters.
- Separate language claims from narrative-function and identity claims.
- Record historical dependence, common inheritance, convergence, and selective
  comparison as competing explanations.

## Priority 4 — Chronology pilot

Use the precessional framework as the third pilot because it differs from the
first two: it combines an observed astronomical cycle, historical claims about
ancient awareness, a framework convention for age boundaries, and derived
event placement.

## Priority 5 — Derivative consistency

- Inventory public `framework` pages and group them by controlling claim.
- Detect contradictory renderings of linguistic or chronological assertions.
- Define a low-cost way for pages to declare `core_claim_ids` and
  `core_version` without changing current URLs.
- Extend the API only after the core fields are stable enough to expose.

## Research standard

No priority advances by producing more confident prose. Progress requires
better claim boundaries, source access, comparison, discriminating questions,
or review records.
