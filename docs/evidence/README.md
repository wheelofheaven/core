# Evidence maps

An evidence map records, for one core claim, the exact passages inspected, the
source-language observation each supports, how the framework reads it, the
strongest mainstream alternative, relevant scientific context, the critical or
source-history explanation, and the dependencies among sources that look
independent but are not.

These maps are `scoped`, not `reviewed`. They lay out what a reproducible
review would have to weigh; they are not themselves that review. A row's
existence is not evidence for the claim — a mainstream-alternative or
critical-explanation cell may be the stronger reading.

## Column meaning

| Column | Records |
| --- | --- |
| Passage / locator | The exact stable locator inspected |
| Source-language observation | What the wording supports at the textual level, before interpretation |
| Canonical interpretation | How the Wheel framework reads the passage |
| Mainstream alternative | The strongest non-framework reading in scholarship |
| Scientific / historical context | Relevant external context, where any exists |
| Critical / source-history explanation | The source-critical or reception account of why the passage reads as it does |
| Dependency note | Whether this source is independent of the others in the map |

## Maps

Every claim in the catalog has a map at `woh-claim-XXXX-evidence.md`,
matching its record ID. The pilot maps
([woh-claim-0001](woh-claim-0001-evidence.md),
[woh-claim-0002](woh-claim-0002-evidence.md)) remain the fullest examples of
the column discipline; the report layer extracted from claim 0001 is mapped
separately in [woh-claim-0070](woh-claim-0070-evidence.md).
