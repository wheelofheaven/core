# Comparative method

Cross-tradition comparison is central to Wheel of Heaven and especially prone
to overstatement. Every comparison should name which relationship it proposes.

## Relationship types

| Relationship | Question |
| --- | --- |
| Resemblance | Do selected features look or function alike? |
| Typological parallel | Do features occupy comparable narrative or social roles? |
| Historical dependence | Did one record borrow from, respond to, or transmit another? |
| Common inheritance | Do records descend from an earlier shared tradition? |
| Convergent development | Could similar conditions have produced similar motifs independently? |
| Referential identity | Do two names or traditions identify the same entity or event? |

Evidence for one relationship does not automatically support another.

## Minimum comparison record

A serious comparison identifies:

- exact passages and editions;
- languages, dates, genres, and transmission contexts;
- shared features and material differences;
- whether the comparison concerns names, functions, sequences, entities, or
  later interpretations;
- plausible borrowing, inheritance, convergence, and coincidence accounts;
- criteria that would distinguish the preferred relationship;
- which steps are canonical, observational, or interpretive.

## Identity claims

Referential identity is stronger than motif comparison. It requires an account
of how different names, cultural settings, roles, and textual histories can
refer to one underlying subject. A collective-level identity does not entail
one-to-one identity among every member or named figure.

## Linguistic restraint

Popular etymologies must not carry an identity argument when the source
language does not support them. A framework may retain an identity claim while
rejecting a congenial but unsound translation; the argument must then rest on
other evidence.

## Comparison matrix

Evidence maps should eventually use a structured matrix with rows for passages
or features and columns for source date, genre, wording, function, differences,
dependency hypotheses, and confidence in the underlying textual observation.
